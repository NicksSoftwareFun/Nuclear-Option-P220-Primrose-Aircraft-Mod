**Early alpha test build.** One livery so far, the passenger and cargo spaces are still plain, and stats are still being tuned. Feedback welcome.

The P220 Primrose is a domestically built twin-engine airliner flown by Primeva Link (P-LINK), pressed into military service. This build adds the first livery, with damage textures and internal structure, a new flight deck, the THORNE Airborne Laser in the tail cone, a Capacitor Pack for the rear bay, the SpectralEye AEW Radar, thrust reversers and a folding fin for the medium hangar.

### Install

You need BepInEx 5 and Blueprinter. Drop `P220Primrose.dll` into `Nuclear Option\BepInEx\plugins` (replace the 0.2.7-alpha file if you have it) and start the game. That's the whole mod, one file.

**Breaking:** the aircraft key changed to `P220Primrose`, so missions saved with 0.2.7-alpha no longer find the aircraft.

The full list is in [CHANGELOG.txt](https://github.com/NicksSoftwareFun/Nuclear-Option-P220-Primrose-Aircraft-Mod/blob/main/CHANGELOG.txt).
